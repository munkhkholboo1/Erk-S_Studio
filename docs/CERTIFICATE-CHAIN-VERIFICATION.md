# Өглөөний шалгалт

Хоёр тусдаа зүйл: **DevMod дээрх шинэ UI** (нийтлэгдээгүй), ба **гэрчилгээний
үүлний гинж** (бодит өгөгдөл шаардана).

## A. DevMod дээрх шинэ UI

Host дээр **Ctrl+U**, дараа нь төсөл нээх.

### Төслийн мэдээлэл хуудас

| Юу | Хүлээж буй |
|---|---|
| Багийн карт | Ногоон цэг = **«Studio-д онлайн»**, улаан дээр hover хийвэл «Studio-д N цагийн өмнө холбогдсон» |
| Сонсоогүй гишүүн | **Цэггүй**, «Мэдээлэл алга» — улаан биш |
| Гишүүн бүрд | «N эх үүсвэр · N хуудас» эсвэл «Эх үүсвэр бүртгүүлээгүй» |
| Баруун дээд preview | Томорсон, хуудас **бүтнээрээ**, тайралтгүй |

Цэг нь **төслийн бус** — тэр хүн Studio нээлттэй байгааг л хэлнэ. Тиймээс
төслөө нээгээгүй хамтрагч ч ногоон харагдана; шошго үүнийг ил хэлдэг болсон.

### Эх үүсвэр хуудас

| Юу | Хүлээж буй |
|---|---|
| Жагсаалт | **Эзнээр бүлэглэгдсэн** — инициал + нэр + тоо |
| Локал эх үүсвэр | «**Энэ төхөөрөмж дээр**» бүлэгт, **хамгийн доор** |
| Мөр бүр | Хоёр мөр — нэр дээр, дэлгэрэнгүй доор. **Хоолой (`|`) алга** |
| Мөрийн баруун тал | **⋯** товч → зургаан үйлдэл |
| Дээд мөр | **Гурав л товч** (нэмэх, харагдах байдал, барилгын бүлэг) |
| Оношилгоо | Тусдаа бүлэгт (шалгах, лог) |
| Баруун самбар | Товчнууд **алга**, зөвхөн мэдээлэл |

# Гэрчилгээний үүлний гинжийг шалгах

Байгууллагын гэрчилгээ, тусгай зөвшөөрөл нэг хүний Studio-гоос үүл рүү гарч,
төслийн бусад гишүүдийн альбомд хүрэх зам. **Энэ зам production дээр хэзээ ч
бодитоор ажиллаж үзээгүй** — 2026-08-25-ны байдлаар зөвхөн тусгаарласан probe
дээр батлагдсан.

## Яагаад дараалал чухал вэ

2026-08-25-нд хэмжилт хийхээр завдахад **татах зүйл байхгүй** байсныг олов:

```
Алтанхөхийн Очир    баримт 0
Танан цамхаг        баримт 2   serverDocumentId ""   ← зөвхөн локал
Erk-S LLC           баримт 2   serverDocumentId ""   ← зөвхөн локал
```

Тэр байдалд хэмжилт хийвэл `origin=CLOUD: 0` гарч, «үүлний гинж эвдэрсэн»
гэсэн **худал дүгнэлт** гарна. Үнэндээ гинж эвдрээгүй — үүлэнд юу ч байгаагүй.

Тиймээс шалгалт нь **байршуулахаас** эхэлнэ, татахаас биш.

## Дараалал

### 1. Гэрчилгээ серверт гарсан эсэхийг шалгах

Компанийн номын сангийн файлаас:

```
%LOCALAPPDATA%\Erk-S Studio\company-cache\<данс>\companies.json
```

Баримт бүрийн `serverDocumentId` хоосон бол тэр нь **зөвхөн энэ төхөөрөмж
дээр** байна. `documentsPendingCloudSync: true` бол клиент байршуулах ёстойгоо
мэдэж байгаа ч хийгээгүй гэсэн үг.

### 2. Байршуулалтыг ажиллуулах

Илгээгч (`SendOrganizationDocumentsAsync`) нь **компанийн номын санг үүлнээс
шинэчлэх** үед л ажилладаг. Studio-д Компанийн хуудсаа нээж шинэчлүүлнэ.

Дараа нь 1-р алхмыг давтаж `serverDocumentId` бөглөгдсөн эсэхийг хар.

**Хэрэв бөглөгдөөгүй бол зогс** — тэр нь бие даасан алдаа. Хэрэглэгчид ямар
нэг мэдэгдэл гарсан эсэхийг тусгайлан асуу: `documentsPendingCloudSync` нь
`true` хэвээр атлаа хэрэглэгч юу ч хараагүй бол **чимээгүй бүтэлгүйтэл** мөн.

### 3. Төсөл сонгох

Тэр байгууллага **хавсаргагдсан** төсөл хэрэгтэй:

| Байгууллага | Төсөл |
|---|---|
| Танан цамхаг | `STUDIO-20260724-1332` |
| Erk-S LLC | `STUDIO-20260717-1636`, `ATD-SIM-2026-002` |

Баримтгүй байгууллагатай төсөл (жишээ нь МАД, НАНУТО) дээр хэмжилт **хийгдэхгүй**.

### 4. Синк хийх

**Төсөл нээх нь синк биш.** Бүрэн синк хийх шаардлагатай — эс бөгөөс
snapshot шинэчлэгдэхгүй.

### 5. Хэмжих

`certprobe` хэрэгслээр (зөвхөн уншина, төслийг өөрчлөхгүй):

```
origin=CLOUD гарч ирсэн эсэх        ← гинж ажилласны шинж
director утгатай                     ← салгалт захирлыг алдаагүй
designRepresentative хоосон          ← автомат томилолт арилсан
```

## Хүлээж буй үр дүн ба суурь

2026-08-25-ны суурь (18 төсөл):

```
origin=library : 20        origin=CLOUD : 0
захирал хоосон : 2
архитектор     : 12 толин үлдэгдэл, 6 хоосон
```

Хэмжилтийн дараа `origin=CLOUD` **тэгээс их** байх ёстой. Толин үлдэгдэл нь
серверийн хоосон утгаар дарагдах ёстой.

## Тэмдэглэл

**Алхам 2 нь SRV-ийн `0fc3954` засварын шууд шалгалт болно**: тэр засвар нь
баримтыг **төсөл хавсаргагдсаны дараа** байршуулахад төслийн snapshot-д хүрдэг
болгосон. Хуучин зан төлөв нь эсрэг дараалалд л ажилладаг байсан — эхлээд
байршуулж, дараа нь төсөл үүсгэвэл. **Бодит хэрэглэгч хэзээ ч тэгдэггүй.**
