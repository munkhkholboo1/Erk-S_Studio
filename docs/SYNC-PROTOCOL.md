# Erk-S Sync — синкийн протокол (syncProtocol)

Эзэн, 2026-10-26: «вершний зөрүү хэт их биш бол синк асуудалгүй явдаг болгоорой … синктэй холбоотой шинэчлэлт байгаа
нөхцөлд л шинэчлэхийг шаарддаг байх хэрэгтэй».

- `SyncLagging.Protocol` (ErkS.Sync.Core) — бүхэл тоо. Studio-гийн хувилбар бүрт БИШ, зөвхөн хуучин SYN-тэй синкийг эвдэх
  өөрчлөлтөд (index / chunk / redaction / хамтын файлын гэрээний формат, дугаарлалт, аюулгүй байдал) нэмэгдэнэ.
- SYN session body-д `clientVersion` (мэдээлэл) ба `syncProtocol` илгээнэ. Сервер `minSyncProtocol` буцаана; түүнээс доош
  (эсвэл илгээгээгүй) төхөөрөмжийн бичих хүсэлт 426 `sync_client_outdated`. Status: «Erk-S Sync-ийн шинэчлэл шаардлагатай
  (синкийн дүрэм өөрчлөгдсөн)».
- Хоцорсон гишүүн = 24 цагаас дээш офлайн, эсвэл `syncProtocol` < min. Studio-гийн хувилбар хуучин байх нь хоцролт биш.
