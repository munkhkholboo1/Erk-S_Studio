Арга: 263 эх файлыг рефлекс + эх кодын лавлагаагаар нэг удаа шүүрдсэн

## 1. Дуудагчгүй нийтийн API

**Тэг.** `StudioAccountService`-ийн нийтийн арга бүр үйлчилгээний давхаргаас гадуур
дуудагчтай. Өнөөдөр гурвыг илрүүлж, `ResumeBotStateAsync`-ыг устгасны дараа энэ
ангилал цэвэрлэгдсэн бөгөөд рефлексийн тест (`BotInvitationReachabilityTests`) нь
бот-аргуудыг цаашид хамгаална.

## 5. Хуурамч эерэг (үлдэгдэл БИШ)

Шүүрдэлтэд гарсан боловч жинхэнэ хэрэглээтэй: `StudioCloudProjectSurfaceTheme`,
`StudioCloudStageInstance`, `StudioCloudOrganizationAssignment`,
`StudioDeviceBoundRequest`, `StudioSourceRemoteRetirementStatus`,
`StudioDeviceFingerprintValidation` — эдгээр нь нэг файл дотроо эцэг DTO-доо
эсвэл суурь ангидаа хэрэглэгддэг. Мөн бүх диалогийн ангиуд (`BotAssignmentDialog`
гэх мэт) нэг файлдаа зарлагдаж, тэндээ дуудагддаг.

---

## Дүгнэлт

Устгах нэр дэвшигч **нэг** (`StudioDeviceKeyPair`, P2P-ийн шийдвэрээс хамаарна),
«хэрэглэгдээгүй дүрэм» **гурав** (устгах эсэх нь бүтээгдэхүүний шийдвэр, техникийн
биш). Хуучин форматын код бүгд амьд, шилжилт дуусаагүй.

Хамгийн том илрэл нь **дуудагчгүй нийтийн API тэг байгаа нь** — өнөөдрийн
рефлексийн дүрэм тэр ангиллыг цэвэрлэсэн ба цаашид хамгаална.
